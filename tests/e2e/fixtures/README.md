# Fixture média

`media-demo.webm` est un court clip VP8 de 64 × 64 pixels, sans son, créé pour ces tests avec un canevas Chromium et `MediaRecorder`. Ses deux aplats de couleur sont générés, sans fichier ni contenu tiers. Le test l’intercepte sous une URL locale et vérifie une lecture réelle, le chargement d’une piste WebVTT de test et la mise en pause lors du changement de diapositive.
